## 关键决策

- **脚本 id 用中文「一路狂飙」**（用户明确要求），与 name 一致。
- **通关设置用 locked 字段类型占位**：config.js 新增渲染分支，显示"自动通关 + 暂不开放"，点击提示暂不开放；渲染无 fieldId 控件，值收集自动跳过。小花仙不使用该类型，零副作用。
- **配置面板复用通用渲染器**：加载 config.schema.js → 上级 config.css/config.js，不加载花朵数据（一路狂飙仅 boolean/integer/select/locked 类型）。
- 功能对照用户一路狂飙 Web 面板（tools/web_panel/：通关/三倍芯片/抢红包/登录配置）。
